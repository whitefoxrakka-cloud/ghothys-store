ANTI-SPAM ORDER (sudah aktif, versi 2026-09-25)
  1. Header Sec-Fetch-Mode/Dest/Site wajib ada dan nilainya sesuai fetch()
     browser. Kalau ketiganya tidak ada, hanya Origin dari ALLOWED_ORIGINS
     yang diterima (browser lawas). curl/python/lynx = 403.
  2. Honeypot: field tersembunyi name="website" di #topup-form. Terisi = 400.
  3. Dwell time: klien kirim t = kapan form dibuka. < 2 detik = 400.
     t kosong/0 tetap diterima agar halaman lama di cache tidak rusak.
  4. Rate limit 5 order / 10 menit / IP (balas 429 + Retry-After).
     Klien otomatis coba lagi sekali setelah jeda 3,2 detik.
  5. Cek duplikat Order ID di Airtable (balas 200 duplicate, tidak kirim
     ulang ke Discord/Telegram).
  6. Validasi ketat: order_id /^INV-\d{8}-\d{1,6}$/, game & uid wajib,
     price 0-5.000.000, panjang tiap field dibatasi.
  CATATAN: ini menahan spam/bot, bukan otentikasi. Kalau butuh proteksi
  lebih ketat (mis. wajib login/OTP), itu perubahan terpisah.

  PENTING: relaySecret di js/notify-config.js SUDAH DIKOSONGKAN dan
  secret lama sudah dirotasi. Jangan pernah menaruh secret di file publik
  (view source bisa dilihat siapa pun). Untuk tulis konten owner, browser
  memakai token panel admin (sessionStorage admin_jwt) -> wajib login di
  /admin/ pada tab yang sama.

ROTASI PASSWORD ADMIN
  Password owner TIDAK disimpan di repo. Sumber nilai saat ini:
  backend/scripts/seed-admin.js (MASIH plaintext di repo - Ideally dihapus setelah
  worker siap, lalu pakai langkah di bawah).

  1. Buat hash baru (Node, PBKDF2-SHA256 60.000 iterasi, salt 16 byte, hash 32 byte):
       node -e "const c=require('crypto'),fs=require('fs');\
       const p=fs.readFileSync('D:/Proyek & Karya/toko baru/backend/scripts/seed-admin.js','utf8')\
       .match(/TARGET_ADMIN_PASSWORD\s*=\s*'([^']+)'/)[1];\
       const s=c.randomBytes(16),h=c.pbkdf2Sync(Buffer.from(p),s,60000,32,'sha256');\
       const b=x=>x.toString('base64').replace(/\+/g,'-').replace(/\//g,'_').replace(/=+$/,'');\
       process.stdout.write('pbkdf2$60000$'+b(s)+'$'+b(h))" | npx wrangler secret put ADMIN_PASSWORD_HASH
  2. Ubah TARGET_ADMIN_PASSWORD di seed-admin.js (kalau passwordnya memang diganti).
  3. Kalau mengganti email admin juga: pakai perintah yang sama untuk ADMIN_EMAIL.
  PENTING: Cloudflare membatasi iterasi PBKDF2 maksimal 100.000. Di atas itu
  verifyPassword selalu gagal (login selalu 401) walau hash-nya benar.

     copy worker.js %TEMP%\worker-YYYYMMDD.bak

     ke GitHub Pages (js/*.js, index.html, admin/*). File publik = terbuka untuk

     (nilai lama langsung mati), kosongkan dari file, lalu commit + deploy.
